## Copy Strategy

The final copy should lean on the `5173` portfolio version because it carries the user's researched language: first-person, practical, specific, and emotionally grounded. The `8080` sandbox version is useful because it compresses several ideas into sharper editorial labels, especially:

- "Visual instinct, measurable craft."
- "How the client decides shapes how I work."
- "Collage becomes blueprint."
- "AI as a critique system, not a stylist."
- "Brief -> scoped packets -> verified output."
- "Two gates. Calm control."
- "Small details, quietly decided."

The fusion should not make the page sound like a generic agency process. It should sound like a designer explaining a real working method: adaptive, research-led, AI-assisted, but always decided by human judgment.

## Fact And Claim Check

Confirmed from the current copy and notes:

- The page is about Leon's design process.
- The core promise is turning messy inputs into clear direction.
- The process is adaptive, emotional, research-driven, and not rigid.
- Client decision style changes the process.
- "No" is treated as useful decision data.
- Visual research is sorted by emotion, implementation reality, and pattern fit.

- Agent orchestration, branch gates, typography, refinement, and finish criteria are part of the process story.

Use with care:

- "High-performance digital products" is acceptable as positioning, but it should not become the main process claim unless supported elsewhere.
- Named AI tools should feel like examples from the workflow, not endorsements or the main story.

### 03. Client Clarity

5173 says:

- Kicker: "Client Clarity Layer"
- Heading: "Before I design the interface, I decode how the client makes decisions."
- Clear-Direction Clients: they arrive with examples and firm preferences.
- Unclear-Direction Clients: they struggle with abstract questions but respond to visuals.
- In-Between Clients: they know parts of what they want and what they do not want.
- Rule: `"no" is data. Rejection is not friction - it is direction.`

8080 says:

- Heading: "How the client decides shapes how I work."
- Intro: "Three working modes. Each one earns a different rhythm - and each one treats 'no' as evidence."
- Archetypes: clear-direction client, visual-reaction client, open-discovery client.
- Adds useful signal labels such as "strong references", "decides on sight", and "emotion-led".

Fused copy direction:

- Use 8080's main heading because it is more memorable.
- Keep 5173's detailed archetype descriptions.
- Rename the second and third archetypes to match how they behave, not how "unclear" they are.

Recommended copy:

```text
How the client decides shapes how I work.

Before I design the interface, I decode how the client makes decisions. Three working modes create three different rhythms, and each one treats "no" as evidence.

Clear-direction clients
They arrive with examples and firm preferences. I protect what matters to them, then test strategic variants so the final route still performs.

Visual-reaction clients
They struggle with abstract questions but respond instantly to visuals. I show contrasting routes and use emotional reaction as the fastest alignment signal.

Open-discovery clients
They know parts of what they want and clearly know what they do not want. I map the hard no's, narrow options quickly, and keep momentum without killing discovery.

"No" is data. Rejection is not friction. It is direction.
```

- Body: "Complex briefs are split, scoped with contracts, routed to specialists, and verified against the original intent before they merge."
- Supporting line: "contract: input -> output -> check."
- Step labels: split, route, verify.

Fused copy direction:

- Use 8080's short heading.
- Keep 5173's "not one giant prompt" line because it is concrete and memorable.
- Keep this section practical and operational.

Recommended copy:

```text
Brief -> scoped packets -> verified output.

I do not run one giant prompt and hope it lands. I split complex work into explicit chunks, define input and output contracts, then route each chunk to the right specialist.

Independent tracks run in parallel. Dependent tracks wait for upstream outputs. Before anything is promoted, the result is checked against the original brief so quality is proven, not assumed.

Split: chunks with clear contracts.
Route: the right specialist per chunk.
Verify: delivery checked against the original brief.
```

Fused copy direction:

- Use 8080's heading because it is short and confident.

Recommended copy:

```text
Two gates. Calm control.

One gate before code. One gate before promotion. Entry resolves the correct working branch before any change. Exit checks lineage, validates the target, and requires explicit approval before push or merge.

This keeps feature boundaries clean, blocks accidental sibling merges, and preserves reviewable history across complex sessions.

Entry gate
Before any code lands: branch context confirmed, scope written down, no drift from the brief.

Exit gate
Before anything ships: lineage clean, target verified, review approved, promote on green.
```

### 09. Typography / Hero-First Build

5173 says:

- Body: real copy or evolving words are tested in 1001 Fonts at different sizes.
- Body: sometimes the first font lands; sometimes 8-10 fonts are shortlisted, downloaded, implemented, compared, left alone, and revisited with fresh eyes.
- Steps: Start With Real Words, Explore Broadly, Shortlist + Implement, Step Back + Decide.
- Note: "Typography matters because it communicates tone before a user reads the message."

8080 says:

- Kicker: "Hero-first build"
- Heading: "Typography is the first decision."
- Intro: "Real words, tested in real layouts. Not lorem. The font that makes the headline sound like the brand wins."
- Specimens compare Fraunces, Georgia, Inter, and JetBrains Mono.

Fused copy direction:

- Use the directness of 8080.
- Preserve the researched 5173 process details because they are personal and credible.
- Shorten the section so it does not feel like it is working too hard.

Recommended copy:

```text
Typography starts with real words.

Once the hero direction is clear, typography becomes a serious creative decision, not a quick font pick. I test the actual headline, tagline, or working copy in real layouts so rhythm, spacing, and personality can be judged honestly.

Sometimes the first font lands. Other times I shortlist 8 to 10 options, implement them, compare them inside the design, step away, and come back with a fresh eye.

The font that makes the message sound like the brand wins.

Start with real words.
Explore broadly.
Implement the strongest candidates.
Step back and decide.
```

  - headline rewritten until it reads in one breath
  - motion slowed - meaning over speed
  - color narrowed - restraint over reach

Fused copy direction:

- Use 8080's heading because it has restraint.
- Keep 5173's human-judgment point.
- Merge finish criteria into this closing arc so the ending feels resolved.

Recommended copy:

```text
Small details, quietly decided.

AI accelerates the experiments, but judgment stays human. Cohesion comes from the small decisions: spacing, type rhythm, motion speed, hover behavior, copy pressure, contrast, and states.

I keep refining until the design and the message amplify each other instead of competing for attention.

Spacing tightened where the eye paused.
Headlines rewritten until they read in one breath.
Motion slowed when meaning needed room.
Color narrowed when restraint made the system stronger.
Alt text written like the image is missing.

The loop ends after distance and fresh eyes. If the layout, copy, and emotion still hold after 3-4 days, it is finished. If something feels off, I know exactly where to refine.
```
